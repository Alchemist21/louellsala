# Louell Sala Premium Portfolio Website

## How to publish

1. Create a GitHub repository named exactly:
   `louellsala.github.io`

2. Upload `index.html` to that repository.

3. Go to:
   Settings → Pages → Deploy from branch → main → Save

4. Your site should appear at:
   https://louellsala.github.io

## How to edit

Open `index.html` in VS Code and edit the text, links, and sections directly.
